# 医院组织架构功能

组织架构由六类主数据组成：医院/院区、部门、岗位、职级、员工和任职关系。

- 医院/院区：在 `/admin/organizations` 维护机构主体。
- 组织架构：在 `/admin/directory` 维护部门树、岗位、职级、员工和任职。
- 部门支持多级树、同机构编码唯一、部门类型、负责人、排序和启停。
- 岗位描述工作职责，例如医生、护士长、行政专员。
- 职级描述人员等级，独立于岗位，例如 M1、P5、主任医师级。
- 员工档案独立于登录账号；账号通过 `employeeId` 与员工绑定。
- 任职关系连接员工、医院、部门、岗位和职级，支持一人多部门或多院区任职，并保证只有一个主任职。

删除保护会阻止删除仍有下级部门或任职引用的部门，以及仍被有效任职使用的岗位、职级和员工。

接口统一位于 `/admin/iam`，需要 `iam:directory:manage` 权限。
