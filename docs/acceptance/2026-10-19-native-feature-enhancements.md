# 原生移动端功能缺口与产品增强验收记录（2026-10-19）

## 验收范围

- 教师监考任务的确认、签到和调换申请。
- 督导任务的接受、教师凭证核验、动态评价和完成，授课教师签发一次性凭证。
- 家长多子女切换，以及成绩、家校通知按子女筛选。
- 课表周次记忆、长文本输入、消息设置、隐私与安全和缓存清理。
- Android 与 iOS 原生界面、真实接口、Debug/Release 构建及模拟器启动。

验收连接隔离数据库 `chronos_handoff_verify_20261009`，后端端口 `8080`。业务验收数据保留；仅为移动端登录临时调整的三个账号密码在验收后恢复并使临时会话失效。

## 功能闭环

- Android、iOS 教师工作台增加“监考任务”。列表读取本人监考安排，可确认任务、在服务端允许的时间窗口签到、填写多行原因并申请调换；所有服务端失败原因直接显示。
- Android、iOS 增加督导任务原生页面。督导员可以接受任务，使用授课教师签发的 `TEACHER_QR_V1` 短时凭证签到，读取已发布的动态评价表单，校验必填项，提交评价后完成任务。
- 授课教师工作台增加“课堂督导核验”，可为本人涉及的督导任务签发并复制一次性签名凭证。督导入口按服务端原子权限展示，不依赖工作台角色名称。
- 家长工作台支持多个已绑定子女切换，成绩按当前子女加载；家校通知支持“全部子女”或指定子女筛选。角色文案统一为“家长”。
- Android 课表按登录账号保存所选周次，“本周”可恢复默认；请假、出差、用车用印、家长反馈、监考调换及动态流程 `TEXTAREA` 使用真正可扩展的多行输入。
- 两端“我的”页面补齐系统通知设置、隐私与安全说明、离线缓存清理和动态版本号。新增 iOS 界面各自位于独立 Swift 文件，Android 界面各自位于独立 Java 文件。
