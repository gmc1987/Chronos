## 本轮修复与边界

- 学生门户顶部曾误用默认“教职工”标签。现在使用教育身份绑定的 `profileTypes` 决定缺省身份标签，工作台和直接打开课表 URL 都显示“学生”；见 [修复后截图](2026-10-09-student-role-label-fixed.png)。前端 `npm run build` 通过。
- 学生账号此前因没有字面上的 `STUDENT` 角色码，门户未展示“学生学习台”卡片。现在以已核验的教育档案身份补齐卡片判断；浏览器可见卡片并可进入本人“我的成绩”页面，当前账号暂无已发布成绩。见 [工作台截图](2026-10-09-student-persona-card-fixed.png)。学生尝试直接打开后台排课 URL 被路由重定向至门户，见 [拒绝截图](2026-10-09-student-admin-denied.png)。
- 排课基础链条通过浏览器；复杂周型、并发容量、校历补课、考试占课、真实请假代课、跨范围权限、通知全量投递恢复分别留在闭环台账 #02、#06、#08、#16，不由此次结果代替。
