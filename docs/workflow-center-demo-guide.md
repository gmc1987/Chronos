# 流程中心演示数据使用说明

## 导入

1. 至少启动一次 `hospital-app`，确认 Hibernate 已创建最新表结构。
2. 执行：

```bash
psql -h localhost -p 5432 -U Chronos -d Chronos \
  -f docs/sql/workflow-center-demo-data.sql
```

脚本采用固定 ID 和 upsert，可重复执行；它不会删除非演示数据，仅会重建三个演示流程的连线。

## 验证场景

### 请假审批

- 张三发起2天请假：张三 → 李经理 → 结束，验证默认分支。
- 张三发起5天请假：张三 → 李经理 → 王HR → 结束，验证 `days > 3` 条件。
- 在李经理任务上测试退回、转办、加签和抄送。

### 差旅审批

- 张三发起差旅：李经理审批后，赵财务和孙财务同时收到任务。
- 任意一名财务通过后流程结束，另一人的任务应自动取消，验证 `ANY` 或签。

### 采购审批

- 金额小于10000：李经理 → 钱采购 → 结束，验证默认分支。
- 金额大于等于10000：李经理 → 赵财务和孙财务全部通过 → 钱采购 → 结束，验证 `ALL` 会签。
- 采购节点只有“建议供应商”可编辑，其余字段只读，用于验证字段权限。

### SLA与监控

- 人工任务配置了24或48小时办理期限。
- 在任务中心点击“催办”，验证 `remindedAt` 和审计记录。
- 管理端流程列表顶部验证实例、运行中、完成、待办和超时统计。

## 说明

演示定义直接以 `PUBLISHED` 状态写入 Chronos 业务表，适合验证当前运行时、表单、任务和画布加载。脚本不会写入 Flowable 内部表。若需要验证 Flowable BPMN 部署，请在管理端为演示流程创建新版本，再执行发布。
