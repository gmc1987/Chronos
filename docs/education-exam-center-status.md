# 考试中心实施状态

更新时间：2026-09-15

## 已落地

- 考试计划、具体科目场次、考场、学生座位、监考任务、监考调换记录的数据模型和教育应用迁移脚本。
- 考试类型字典、按人数增配监考规则、主副监考岗位、按学期工作量排序的候选教师及自动排监考。
- 草稿新增与删除、计划及无考场场次编辑、冲突预览与发布门禁；发布前检查考场、考生、监考教师和日期课表。
- 已发布考试反向约束周课表保存、日期调课、课表发布和版本回滚；同学期资源写操作使用 PostgreSQL 事务锁串行化最终校验。
- 教师门户监考任务、确认收到、申请调换；考务后台审批或应急替补；学生门户查看已发布考试。
- 发布、调换申请和处理结果通过现有通知 Outbox 投递；关键处理动作写入平台审计日志。
- 考试计划、监考排班与调换、考场管理、试卷分析现已对应四个独立菜单路由；试卷分析支持场次题目、考生逐题得分、评分覆盖率、平均分、得分率和 CSV 导出。
- 校级或受影响范围的考试占课审批，审批通过后自动生成日期课表停课例外，并保留影响快照和审批轨迹。
- 机动监考池、教师考前报到、缺勤升级和自动启用合格替补监考。
- 连续监考上限、跨校区通勤间隔、学科资格以及已批准请假联动校验。
- 已发布考试的改期、换考场、取消场次和取消计划审批；批准后递增发布版本并重新校验资源。

## 尚未落地的业务闭环

1. 大规模排考候选方案、多方案比较与座位编排优化；当前座位按选择或行政班导入顺序递增。
2. 试卷分析当前以手工维护场次题目和逐题得分为数据入口；尚未与题库版本、阅卷系统、成绩中心建立自动同步，也没有试卷版本冻结和复核发布流程。

- 详细账号、业务数据 ID 和手工复查路径见 `docs/education-exam-center-production-demo-guide.md`。
