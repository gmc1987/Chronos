# 学校走班排课模块

## 模块边界

`education-class-scheduling` 是教育行业专属模块，仅由 `education-app` 装配，
医院版本不会加载该模块。模块不向 IAM、工作流等公共表追加教育字段。

## 当前功能

1. 按学期维护走班教学任务，包括课程、教学班、任课教师、学生人数和周课时。
2. 维护教室、教学楼、容量和教室类型。
3. 按星期、节次和授课周次维护周课表。
4. 周次有交集时检查教师冲突、教学班冲突和教室冲突。
5. 检查教室是否启用以及容量是否满足教学班人数。
6. 已被课表引用的教学任务和教室不允许直接删除。
7. 权限区分为 `education:scheduling:view` 和 `education:scheduling:manage`。

管理端地址：`/admin/education/scheduling`。

数据库初始化脚本：`docs/sql/education-class-scheduling-v1.sql`。

## 已完成的生产增强

- 学年学期、课程库、教师、学生、行政班和专业主数据。
- 年级、学科、家长监护关系和教师任教关系。
- 教学班学生成员、退选及学生选课冲突检查。
- 单双周、连堂、跨节次和教师禁排时间基础约束。
